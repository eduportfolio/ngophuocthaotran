Independent Research
Bioinformatics & Machine Learning

Applying Genomic Clustering Algorithms for Asthma Endotype Prediction and Stratification

Developed an independent computational project focusing on molecular heterogeneity in respiratory diseases. By implementing **unsupervised machine learning algorithms (K-means and Hierarchical Clustering)** on public transcriptomic data from patient airways, the project aims to identify distinct asthma endotypes. Identifying these genetic clusters supports precision medicine by predicting patient risks, understanding specific pathogenic pathways, and facilitating targeted clinical diagnosis.

Bioinformatics Cluster Analysis Genomic Data Precision Medicine
